# 环境变量管理器

环境变量管理器（EnvironmentManager）是一款面向 macOS / Linux 的桌面工具，通过图形界面统一管理 Bash、Zsh 的环境变量、PATH 和自定义脚本，并生成可供终端加载的 Shell Profile，减少手工维护 Shell 配置文件的工作。

## 环境变量与预设

按用途将配置组织成环境块，例如开发工具、网络代理或命令目录。每个环境块包含一组变量和一组 Shell 子块，支持新建、编辑、复制、删除、启用与停用，也可以通过拖动调整顺序。

每个环境变量都可以设置名称、值、用途说明，以及是否启用、是否加入 PATH。预设功能保留，目前预设列表为空；也可以导入完整 JSON 配置。

变量值支持通过 `${HOME}` 引用系统主目录，以及通过 `${其他变量的key}` 引用其他变量。`HOME` 是内置保留变量，不能作为用户定义的 Key。

## PATH 管理

集中管理命令搜索目录，按环境块顺序放在现有 PATH 前面，让这些目录中的命令优先匹配。配置中重复的目录只生成一次；重复加载 Profile 会再次加入这些目录。所有变量都需要填写 Key，勾选 PATH 后会同时导出该变量并将其值加入 PATH。

## 自定义 Shell 脚本

在环境块内添加 Shell 子块，用于管理函数、别名和工具初始化脚本。每个子块可单独命名、编辑、复制、删除、启用、停用和排序。停用环境块会同时停用其中的变量和脚本。

加载 Profile 时，先按环境块顺序设置变量并执行 Shell 子块，最后一次性将所有启用的 PATH 目录放在现有 PATH 前面。

## Profile 生成与 Shell 接入

根据启用的环境块生成统一的 Shell Profile，支持自定义输出路径和手动生成。所有配置在编辑后自动保存；只有在“预览与检查”页面点击“生成 Profile”并确认修改后，才会写入本地 Profile 文件。

可以选择将 Profile 接入 `.bashrc`、`.zshrc`、`.bash_profile` 或 `.profile`。接入时只添加或更新应用管理的加载片段，保留文件中的其他配置。

## 预览与检查

写入文件前可查看生成的 Profile、PATH 顺序，以及 Profile 和 Shell 配置文件的修改差异。支持检查非法变量名、空值、重复变量名，以及 PATH 项是否能静态解析为绝对路径；不检查目录是否存在。

## 配置导入导出与备份

环境配置和设置保存在 Tauri 应用数据目录的 `config.json`，可通过 JSON 文件导入、导出和迁移。导入默认用文件中的完整配置替换当前配置；设置页也可清空当前配置并恢复默认设置。新配置使用 v2 格式；读取旧版 v1 配置时，独立 Shell 块会转换为同名环境块中的 Shell 子块，保留顺序和启用状态。

支持使用 GitHub Token 将配置备份到私密 Gist，并从 Gist 恢复。JSON 导入和导出保留 GitHub Token；Gist 备份中的 Token 字段使用占位符，恢复时沿用当前设备输入的 Token。配置编辑后自动保存，Gist 同步由用户手动发起。

## 工程中的配置流

`src/pinia/config.ts` 是运行期间配置的唯一可写入口。页面与组件读取只读配置，并通过 store action 提交编辑；页面自身仅保存选中项、搜索、弹窗和异步检查结果。新建、编辑与导入都会触发自动保存；生成 Profile 和 Gist 备份会先等待当前配置写入完成，再取得独立快照。

`src/services` 负责配置校验、持久化、Shell 生成和外部操作。Tauri 文件系统、窗口关闭和拖拽使用的窗口监听也集中在这里。配置加载失败时，store 会阻止编辑和保存，避免用默认配置覆盖原始文件。

## 版本维护

应用版本以 `package.json` 的 `version` 为准。更新它之后执行 `npm run sync:version`，将版本同步到 Cargo 包、Tauri 配置和 `src/consts.ts`；应用侧栏从 `src/consts.ts` 读取版本号。

## macOS 发布

推送与 `package.json` 版本相同的标签后，GitHub Actions 会在 Apple Silicon 运行器上构建 `aarch64-apple-darwin` 的 DMG，并上传到该标签对应的 GitHub Release。

发布包使用临时签名，未经过 Apple 公证；macOS 首次打开时可能要求在“系统设置 → 隐私与安全性”中允许运行。
